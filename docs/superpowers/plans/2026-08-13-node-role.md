# node_role 三角色 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agent 用 `config.yml` 的 `node_role` 声明 generic / xpanel / openwrt，Dashboard 存下来，X-Panel 页和升级 API 只接受 `xpanel`。

**Architecture:** 不改 proto。Agent 按现有 `xpanel_name` 路径在 gRPC metadata 里带 `node-role` / `node_role`。Dashboard 在 `authHandler.check` 写入 `Server.NodeRole`。代码默认空；`xpanel` / `openwrt` 只由安装包配置写入。

**Tech Stack:** Go 1.26、gRPC metadata、GORM AutoMigrate、React admin-frontend、vitest

**Spec:** `agent/docs/superpowers/specs/2026-08-13-node-role-design.md`

**协作规则：** `XPANEL_COLLABORATION.md` 禁止未经用户要求 commit。下面每个 Commit 步骤默认跳过；只有用户明确说「提交」时才执行。三个 git 仓库分开：`agent/`、`nezha/`、`admin-frontend/`；Task 7 在 `/Users/kevin/Data/Project/panel/x-panel`。

func normalizeNodeRole(value string) string {
	switch strings.ToLower(strings.TrimSpace(value)) {

	default:
		return ""

}

func persistNodeRole(serverID uint64, role string) error {
	if err := singleton.DB.Model(&model.Server{}).
		Where("id = ?", serverID).
		Update("node_role", role).Error; err != nil {
		return err
	}
	var updated model.Server
	if err := singleton.DB.First(&updated, serverID).Error; err != nil {
		return err
	}
	if current, _ := singleton.ServerShared.Get(serverID); current != nil {
		updated.CopyFromRunningServer(current)
		singleton.ServerShared.Update(&updated, "")
	}
	return nil
}
