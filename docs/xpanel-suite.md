# X-Panel 四件套

本仓库是定制 Nezha Agent，作为独立服务连接 Dashboard。它和另外三个私有仓库是一套：

| 仓库 | 角色 | 分支 |
| --- | --- | --- |
| https://git.qm.mk/kevin/x-panel | 面板本体 | `main` |
| https://git.qm.mk/kevin/agent | 本仓库，定制 Agent | `main` |
| https://git.qm.mk/kevin/nezha | Dashboard | `master` |
| https://git.qm.mk/kevin/admin-frontend | 管理后台前端 | `main` |

协作规则在 x-panel 仓库的 `docs/xpanel-collaboration.md`，仓库对照在 `docs/repository-map.md`。
